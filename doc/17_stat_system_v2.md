## 3. สูตรค่าอนุพันธ์
| ค่า | สูตร |
|---|---|
| HP | 200 + STA × 14.179 |
| **Max SP** | **round(70 + STA × 0.8)** |
| **SP Regen / เทิร์น** | **+6 SP (คงที่)** *(+6 SP เมื่อโจมตีธรรมดา · ตัวสำรองข้างสนาม +10 SP/เทิร์น)* |
| ATK | STR × 2.805 |
| DEF | 10 + STA × 0.721 |
| SPD | 70 + AGI × 0.788 |
| HIT | 100 + AGI × 0.2 |
| FLEE | AGI × 0.441 |
| CRI% | min(40, 5 + AGI × 0.159) |
| CRI DMG | 1.4 + STR × 0.004 (เท่า) |
| Armor Break % | min(50, STR × 0.31) |
| Block % | STA × 0.38 |

**กฎการรบที่ใช้ในซิมูเลเตอร์**
- โอกาสโดน = clamp((HIT ผู้โจมตี − FLEE ผู้ป้องกัน) / 100, 0.5, 1)
- DEF ที่ใช้จริง = DEF × (1 − max(0, Armor Break − Block) / 100)
- ดาเมจ = ATK × ตัวคูณสกิล × 100/(100 + DEF ที่ใช้จริง) × ตัวคูณธาตุ × (คริ ? CRI DMG : 1) × สุ่ม 0.95–1.05
- พญานาคคำนวณ HP และ DEF ตามสูตรแล้วคูณ 1.2 และ 0.5 ตามลำดับ
- ฟีนิกซ์คำนวณ HP และ ATK ตามสูตรแล้วคูณ 1.05 ทั้งคู่

## 6. ข้อค้นพบสำคัญจากการจำลอง
1. **เปลี่ยนระบบสเตตัสอย่างเดียวไม่พอ** ต้องจูนสัดส่วนและสัมประสิทธิ์ ตารางที่ยังไม่จูนแย่กว่าเดิมเพราะ HP+DEF ของสายถึกทบกัน
2. **Armor Break และ Block** คานสายถึกได้ ควาย>เต่า (ได้ธาตุ) ลดจาก ~99.6% เหลือ 76%
3. **ลด DEF พร้อมเพิ่ม HP ทำให้ตัวนั้นแข็งขึ้น** (HP เพิ่มดาเมจที่ทนได้ตรง ๆ แต่ DEF ลดผลได้จำกัด) การปรับพญานาคจึงต้องคุมให้ HP เพิ่มไม่เกินส่วนที่ DEF ลด ค่าที่เลือก (×1.2 / ×0.5) ให้ SS ใกล้กันที่สุด
4. **เกจ SS เบา (30 + 3)** แก้ปัญหา SS ไม่ได้ใช้สกิลประจำตัวได้โดยไม่ทำให้ SS ครองเกมเกินไป

## 7. ปัญหาที่ยังเหลือ
- **คู่ SS ตัวต่อตัวยังไม่สม่ำเสมอ**: win-rate รวมของ SS ทั้ง 3 ตัวเท่ากัน (85.0 / 82.7 / 83.2%) แต่มังกรฟ้าชนะฟีนิกซ์ 70.3% และฟีนิกซ์ชนะพญานาค 69.3% เป็นรูปแบบแพ้ชนะวนเป็นวง (เกือบ rock-paper-scissors) ซึ่งยอมรับได้ในเกมที่ธาตุครองเกม การเพิ่ม ATK/HP อย่างเดียวไม่ทำให้ทั้งสามคู่เข้า 40–60% ถ้าต้องการปรับต่อ ให้ลอง SPD ของมังกรฟ้า −5% หรือเกจเริ่มต้นเฉพาะตัว
- ฟีนิกซ์ใช้สกิลประจำตัว ≥1 ครั้งเพียง 86.7% ของไฟต์ (ต่ำสุดใน SS)
- **S ชนะ SS เมื่อธาตุเสมอ 16.4%** ต่ำกว่าเป้า 20% เล็กน้อย (ยอมรับได้ถ้าต้องการให้ SS ศักดิ์สิทธิ์)
- ค่าความต่างเล็กน้อย (1–2%) อาจเป็นความผันผวนจากการสุ่ม ใช้ 5,000 ไฟต์ต่อคู่

**สถานะ:** ผู้ออกแบบพอใจกับระบบนี้และใช้เป็นฉบับปัจจุบัน

## 8. ข้อจำกัดของการจำลอง
- เป็นการรบ **1v1** ไม่รวมตัวสำรองและปุ่มสลับตัว
- **ไม่รวมสถานะผิดปกติ** (ไฟไหม้ แช่แข็ง สตัน พิษ ฯลฯ) และบัฟ/ดีบัฟ
- สกิลประจำตัวยิง **อัตโนมัติเมื่อเกจเต็ม** (ในเกมจริงผู้เล่นกด)
- ลำดับสกิล 4 ช่องตั้งเป็น L, M, S, S และไม่รวมโบนัสธาตุสกิลตรงกัน (+20%)
- ค่า HIT, FLEE, CRI ฐาน, CRI DMG ฐาน และสัมประสิทธิ์อนุพันธ์ ผมตั้งขึ้นเองและจูนด้วยอัลกอริทึมให้เข้ากับเกณฑ์ ผลจึงมีส่วนที่ fit กับฮีโร่ 12 ตัวนี้โดยเฉพาะ
- ฮีโร่ครอบคลุมแค่ 12 ตัว ยังไม่ครบ 10 ธาตุและประเภทสัตว์อื่น
- ต้องทดสอบซ้ำเมื่อกำหนดสถานะผิดปกติและค่าจริงใน 04 และ 07 ครบ
