# 01 ภาพรวมและเสาหลักการออกแบบ

## ภาพรวม
| หัวข้อ | รายละเอียด |
|---|---|
| แนวเกม | Auto Battle · Turn-based · Collection |
| มุมมอง | 2D Side-view |
| รูปแบบต่อสู้ | 1 ต่อ 1 ทีม 2 ตัวสลับกันลงสนาม |
| จุดขาย | "ถ้าสัตว์ทุกตัวบนโลกกลายเป็นฮีโร่" + ฟักไข่ + สกิลสุ่มตามโอกาส 4 ช่อง |
| แพลตฟอร์ม | มือถือ (iOS/Android) หลัก, PC ภายหลัง |
| กลุ่มเป้าหมาย | อายุ 12-35 ชอบสะสม ชอบสัตว์ เล่นสบาย ไม่ต้องกดตลอด |
| รายได้ | F2P + Gacha (ไข่) + Battle Pass + โฆษณาสมัครใจ |

**Elevator Pitch:** เด็กชายหลุดเข้าโลกที่สัตว์ทุกชนิดตื่นพลังธาตุเป็นฮีโร่ ต้องฟักไข่ รวบรวมฮีโร่ และรักษาสมดุลก่อน The Void จะลบทุกอย่าง

**โทน:** นวนิยายแฟนตาซีเปิดอ่านทีละบท, cozy pixel art อบอุ่น ละมุน, Active Story (ผู้เล่นเลือกเองทั้งหมด)

## Design Pillars (กฎที่ต้องไม่ฝ่าฝืน)
1. **สัตว์ทุกตัวคือฮีโร่** — บุคลิก ธาตุ สไตล์รบต้อง "ใช่" กับธรรมชาติจริง (เสือดำ=มืด/ลอบโจมตี, ปลาไหลไฟฟ้า=สายฟ้า)
2. **วางแผนก่อน ตื่นเต้นทีหลัง** — ตัดสินใจทีม/ธาตุ/สกิลก่อนรบ แล้วดูผล Auto ที่สุ่มพอให้ลุ้น
3. **ฟักไข่คือหัวใจความตื่นเต้น** — ทุกครั้งต้องรู้สึกพิเศษ
4. **เล่นสบายแต่มีมิติ** — รอบละ 1-3 นาที แต่ต้องจัดสกิล/ธาตุอย่างฉลาดถึงจะเก่ง
5. **ความฝันวัยเด็ก** — อบอุ่น ผจญภัย มีความหวัง
6. **ผู้เล่นขับเคลื่อนเรื่อง ไม่บังคับ** — ไม่มีฉากบังคับดู ไม่มีเควสต์ลำดับบังคับ ไม่มี tutorial ที่ข้ามไม่ได้
7. **Cozy fantasy novel** — ภาพ เสียง UI ให้ความรู้สึกเปิดหนังสือผจญภัย
