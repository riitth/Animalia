## 1. บทนำและแนวคิดการออกแบบ (Design Philosophy & Balance Core)

### 1.1 วัตถุประสงค์ (Objectives)
ขยายขุมพลังสัตว์มายา สัตว์ในตำนาน และสัตว์ในนวนิยายปรัมปราของโลกให้ครอบคลุมสาย **TANK (ผู้พิทักษ์และตั้งรับ)** ครบทั้ง 11 ธาตุของเกม *Animalia* เพื่อสร้างความสมดุลด้านกลยุทธ์ทั้งในโหมดการเล่น **1v1 Tag Relay** และ **2v2 Tactical Grid Arena** โดยยึดหลัก:
1. **ความสมดุลด้านสถิติ (Stat Balance):** สอดคล้องกับกรอบสเตตัสระดับ SS-Tier Class Budget เท่ากับ **182 พอยต์** อย่างเคร่งครัด
2. **คงเอกลักษณ์และสรีระเฉพาะตัว:** สัตว์แต่ละชนิดต้องมีที่มาทางประวัติศาสตร์และตำนานปรัมปราที่เด่นชัด สอดคล้องกับความเป็น "สัตว์เกราะ/สัตว์หนังหนา/ผู้พิทักษ์" อย่างแท้จริง
3. **ความหลากหลายของเกมเพลย์สายแทงค์ (Tactical Archetypes):** ออกแบบให้มีความหลากหลาย ไม่จำเจ เช่น บาเรียเกราะสะท้อน, ฟื้นฟูเลือดต่อเนื่อง, หักเหวิถีโจมตี, และดูดซับสถานะผิดปกติ

## 2. โครงสร้างสเตตัสและคลาสบัเจ็ต (SS Class Budget Breakdown)

สูตรคำนวณสเตตัสพื้นฐานของเกมอ้างอิงตาม `src/data/heroes.json`:
- **SS Class Stat Budget:** $182$ Points รวม $(\text{STR} + \text{AGI} + \text{STA} = 182)$
- **การจัดสรรสเตตัสสาย Tank:**
  - ค่า **STA (Stamina):** กำหนดไว้สูงเป็นพิเศษ $(92 - 102)$ เพื่อเพิ่ม Max HP $(\times 14.179)$, Base DEF $(\times 0.721)$, โอกาสบล็อก $\text{Block Rate} (\times 0.38\%)$, และ Max SP $(\times 0.8)$
  - ค่า **STR (Strength):** $(42 - 52)$ เพียงพอต่อการสร้างความเสียหายปานกลาง และมีเกราะทะลวง $\text{Armor Break} (\times 0.31\%)$
  - ค่า **AGI (Agility):** $(32 - 44)$ เพื่อรักษา SPD ไม่ให้ต่ำจนเกินไป พร้อมค่า Flee และความแม่นยำพื้นฐาน
- **ตำแหน่งยืนต่อสู้ (Battle Grid Positioning):** ทุกตัวละครสาย Tank มีค่า `preferredRow: "front"` และ `backlineChance: 0` (ยืนแถวหน้า 100%)

### 4.1 ธาตุดิน 🪨 : เสวียนอู่ (Xuanwu) — *พญาเต่าดำทมิฬเทวะ*
- **ID:** `xuanwu` | **Element:** `earth` | **Role:** `Tank` | **Rarity:** `SS` | **Emoji:** 🐢
- **Archetype Allocation:** `STR: 45, AGI: 35, STA: 102` (ผลรวม = 182)
- **Custom Multipliers:** `hp: 1.25, def: 0.55` | **Block Rate Bonus:** $+20\%$
- **ท่าไม้ตาย (Signature):** `กำแพงปฐพีดึกดำบรรพ์`
  - *Effect:* ดาเมจ $\times 2.2$ สร้างโล่ปฐพี $25\%$ Max HP ให้ตนเองและพันธมิตร 1 ตัว ลด CRI Rate ของศัตรูทั้งสนามลง $20\%$ นาน 2 เทิร์น
- **ความสามารถติดตัว (Ability):** `กระดองเต่าผสานอสรพิษ` (`xuanwu_bastion`)
  - *Effect:* เพิ่มโอกาสบล็อก $+18\%$ และเมื่อบล็อกการโจมตีสำเร็จ มีโอกาส $60\%$ สวนกลับทำให้ผู้โจมตีติดสถานะ *กลายเป็นหิน (Petrify)* 1 เทิร์น
- **สกิลเริ่มต้น (Default Skills):** `["earth_l", "earth_m1", "martial_l", "catalyst_l"]`
- **Lore บันทึกตำนาน:** หนึ่งในสี่สัตว์เทพศักดิ์สิทธิ์ประจำทิศเหนือ มีร่างกายเป็นเต่ายักษ์ศิลากระดองดำผสานงูเทวะ เป็นสัญลักษณ์แห่งการป้องกันอันไร้เทียมทานดั่งเทือกเขาหิมาลัย
