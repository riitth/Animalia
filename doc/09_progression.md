# 09 การพัฒนาตัวละคร (Progression)

- **เลเวล:** ใช้เสบียงสัตว์ (อาหาร) ตามธาตุ
- **ดาว ★1-★5:** ใช้เศษวิญญาณ เพิ่มสเตตัส ปลดพาสซีฟ
- **อุปกรณ์:** 3 ช่อง (ผ้าคลุม/เกราะ/เครื่องประดับ) ให้สเตตัสและโบนัสธาตุ
- **Bond:** จับคู่ฮีโร่บางคู่ได้โบนัส เช่น เสือ + ช้าง "เจ้าป่าและราชาแห่งทุ่ง"
- **สารานุกรมสัตว์โลก:** สะสมครบหมวดได้รางวัล พร้อมข้อมูลสัตว์จริง (ให้ความรู้)
- **สกิล:** อัปเลเวล 1-5 ผ่านคัมภีร์ซ้ำ (ดู 07)
