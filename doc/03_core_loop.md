# 03 วงจรการเล่นหลัก (Core Loop)

| ช่วง | วงจร |
|---|---|
| ระยะสั้น (1-3 นาที) | เลือกด่าน → ต่อสู้ Auto → ได้ทรัพยากร/ไข่ → จัดทีม/สกิล |
| ระยะกลาง (รายวัน) | ภารกิจรายวัน → ฟักไข่ → ได้ฮีโร่ใหม่ → ปรับทีมตามธาตุศัตรู → ผ่านบทเพิ่ม |
| ระยะยาว (สัปดาห์-เดือน) | สะสมครบ "สารานุกรมสัตว์โลก" → อัปดาว → ไต่แรงก์ Arena → ปราบบอสกิจกรรม |

## กฎที่เกี่ยวข้อง
- ผู้เล่นเล่นรอบสั้น ๆ ได้ ไม่ต้องกดตลอด (Auto)
- ทุกวงจรต้องมีรางวัลที่ป้อนกลับเข้าวงจรถัดไป (ไข่ ทรัพยากร สกิล)
