# 06 ฮีโร่สัตว์และระดับความหายาก

## ระดับ
| ระดับ | ความหมาย | สิ่งที่ได้ |
|---|---|---|
| B | สัตว์ทั่วไป | สกิลประจำตัว (กดใช้) + **Ability ประจำตัว (พาสซีฟตามธรรมชาติสัตว์)** |
| A | สัตว์ป่า | สเตตัส, สกิลประจำตัว และ Ability แรงขึ้น |
| S | สัตว์หายาก | สเตตัสสูง + Ability ระดับสูง |
| SS | สัตว์มายา | สเตตัสสูงสุด + Ability ระดับตำนาน + โหมดปลุกพลัง (Awakening) |

## หลักการออกแบบ
- ทุกตัวมี "ธรรมชาติจริง → พลังฮีโร่" (เช่น ตัวนิ่มม้วนตัว → เกราะสะท้อน)
- สกิลโจมตี+Utility เสริมกันหรือมีบทบาทชัด
- B ต้องไม่ไร้ค่า: มีที่ทางช่วงต้น-กลาง และมีคอมโบกับสกิลธาตุ
- ระดับสูงต้อง **ไม่ชนะแน่นอน** ธาตุและสกิลยังมีผล

## บทบาท (Role)
Tank · Striker · Assassin (ไว คริสูง) · Controller (สตัน/ชะลอ) · Supporter (ฟื้น/บัฟ)
ทีม 2 ตัวควรจับคู่บทบาทกัน เช่น Tank + Striker
