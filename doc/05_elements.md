# 05 ระบบธาตุ (Elements) — 11 ธาตุ

## ธาตุ
🪨 ดิน · 💧 น้ำ · 🌪️ ลม · 🔥 ไฟ · ⚡ สายฟ้า · ❄️ น้ำแข็ง · 🌿 พืช · ☠️ พิษ · 🌑 มืด · ✨ แสง · 🔮 พลังจิต (Psychic)

## ตารางความสัมพันธ์
ใช้ระบบวงจรธาตุ ทุกธาตุมีจำนวนคู่ได้เปรียบและเสียเปรียบเท่ากัน (ได้เปรียบ 3 / เสียเปรียบ 3)

| ธาตุ | ได้เปรียบต่อ | เสียเปรียบต่อ |
|---|---|---|
| ดิน | สายฟ้า, น้ำ, ไฟ | มืด, แสง, พิษ, พลังจิต |
| น้ำ | ไฟ, พืช, น้ำแข็ง | สายฟ้า, ดิน, มืด |
| ลม | พิษ, แสง, มืด | น้ำแข็ง, พืช, ไฟ, พลังจิต |
| ไฟ | พืช, น้ำแข็ง, ลม | น้ำ, สายฟ้า, ดิน |
| สายฟ้า | น้ำ, ไฟ, พืช, พลังจิต | ดิน, มืด, แสง |
| น้ำแข็ง | ลม, พิษ, แสง, พลังจิต | พืช, ไฟ, น้ำ |
| พืช | น้ำแข็ง, ลม, พิษ | ไฟ, น้ำ, สายฟ้า |
| พิษ | แสง, มืด, ดิน | ลม, น้ำแข็ง, พืช, พลังจิต |
| มืด | ดิน, สายฟ้า, น้ำ, พลังจิต | แสง, พิษ, ลม |
| แสง | มืด, ดิน, สายฟ้า | พิษ, ลม, น้ำแข็ง |
| **พลังจิต** | **พิษ, ดิน, ลม** | **มืด, สายฟ้า, น้ำแข็ง** |

ตรวจสอบแล้ว: ตารางสมมาตรแบบ 1:1 ครบทุกคู่ข่ม (A ชนะ B ⇔ B แพ้ A เสมอ)

> ธาตุที่ **เสียเปรียบกลับกันทั้งสองทาง** ไม่มี และไม่มีคู่ใดข่มกันซ้ำสองทิศ

## ตัวคูณ
| ผล | ตัวคูณ |
|---|---|
| ชนะธาตุ | ×1.3 |
| แพ้ธาตุ | ×0.85 |
| เท่ากัน/ไม่มีความสัมพันธ์ | ×1.0 |

*(ปรับจากเดิม ×1.5 / ×0.75 เป็น ×1.3 / ×0.85 เพื่อให้สเตตัสและการจัดสกิล 4 ช่องมีน้ำหนักมากขึ้น ส่วนธาตุข่มช่วยชดเชยช่องว่าง 1 คลาสได้แบบลุ้นสนุก)*

## หลักการ
- ไม่มีธาตุใดชนะทุกอย่าง
- ตารางต้องไม่ซับซ้อนสำหรับมือถือ
- แสดง **ลูกศรเขียว/แดง** บนศัตรูก่อนเริ่มรบ
- โบนัสธาตุตรงกันของสกิล: ดู 07 (เพิ่มโอกาสออก + ดาเมจสุดท้าย +20%)
