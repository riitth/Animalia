# 11 เศรษฐกิจและรายได้

## สกุลเงิน/ทรัพยากร
| ชื่อ | ชนิด | ใช้ทำอะไร |
|---|---|---|
| เหรียญ | ฟรี | ปลดสกิลเล็ก/กลาง |
| คริสตัลสมดุล | พรีเมียม | ไข่ทอง ฯลฯ |
| เศษวิญญาณ | จากไข่ซ้ำ | อัปดาว/พาสซีฟ |
| พลังอบอุ่น | — | ลดเวลาฟัก |
| เสบียง | — | เลเวลฮีโร่ |
| หินธาตุ | สำรวจ | ปลดแถวธาตุ |
| คัมภีร์สกิล / ชิ้นส่วนบอส | ด่าน/บอส | ปลดและอัปสกิล |

## ช่องทางรายได้
แพ็กคริสตัล · ไข่ทอง · Battle Pass รายซีซัน · ช่องฟักเพิ่ม · สกินฮีโร่ (ไม่กระทบสเตตัส) · โฆษณาสมัครใจลดเวลาฟัก

## หลักการ (ห้ามฝ่าฝืน)
1. เล่นฟรีต้องไปถึงตอนจบเนื้อเรื่องได้
2. ไม่ขายสเตตัสโดยตรง
3. ผู้เล่นฟรีได้ SS ผ่านกิจกรรมและ Pity
4. สกินไม่ขายพลัง
5. โฆษณาเป็นแบบสมัครใจเท่านั้น
